# Privacy Policy

This application is a personal YouTube automation bot for private use only.

## Data Collection
This app does not collect, store, or share any personal data from third parties.

## Google API Usage
This app uses the YouTube Data API v3 solely to upload videos to the owner's 
own YouTube channel. No user data is accessed beyond what is strictly necessary 
for this purpose.

## OAuth Tokens
OAuth tokens are stored as encrypted GitHub Actions secrets and are never 
shared with third parties.
